# Git identity — gajay only

All automated and agent commits should show **gajay**, not Cursor, GitHub Actions bot, or co-authors.

## Configure once

Edit `automation/git-identity.json`:

```json
{
  "name": "gajay",
  "email": "your-github-email@example.com"
}
```

Use the same email as your GitHub account so commits link to your profile.

## Before each commit (agents & local)

```bash
npm run git:author
```

## GitHub Actions

Daily scaffold commits use `configure-git-author.js` when `GIT_AUTHOR_EMAIL` secret is unset.

Optional repo secret **GIT_AUTHOR_EMAIL** overrides email only; name stays **gajay** when the secret is set in the workflow.

## Cursor Automation

- **Run as: Me** (not service account).
- Re-paste the updated prompt from `templates/cursor-daily-implement.prompt.md` (includes no co-author rules).

## Never

- `Co-authored-by: Cursor` or any bot
- Branch prefix `cursor/` (use `daily/` instead)
- PR body lines like "Generated by Cursor"
